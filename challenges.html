Challenges

Not everything worked the first time. Here are the biggest problems we solved.

The clock kept forgetting the time

Every time the system restarted, the time went back to the start.

The fix: setupTime() was running on every boot and overwriting the clock. We stopped it from resetting the time on startup.

The relay restarted the microcontroller

Switching the relay caused a voltage drop (a brownout) that reset the whole system.

The fix: drive the relay through a MOSFET with a flyback diode, which absorbs the voltage spike from the relay coil.

The relay switched on and off too fast

The watering loop toggled the relay many times in a row instead of once.

The fix: we debugged the loop so the relay only changes state when it really should.

The servo didn't move correctly

The PWM pulse was too short, so the servo didn't reach the right position.

The fix: scale the pulse width: width = 4 * width.
