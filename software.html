Software

We wrote the firmware in C using Keil µVision.

Keeping time

When the controller starts, it reads the current time from the real-time clock. The function setupTime() sets the clock, and it must only run once, not every time the system boots.

The watering loop

The main loop checks the time over and over. When it's time to water, it switches the relay on, and when watering is done, it switches it off.

Controlling the servo

The servo's position is set by the width of a PWM pulse. The program calculates this width and sends it to the servo.

The touchscreen menus

The interface has several screens. Each button only works on the screen it belongs to, so a touch on one screen can't trigger a button from another.
